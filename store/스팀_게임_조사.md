# 스팀(Steam) 게임 조사 노트

작성일: 2026-08-14  
목적: 수업용 스토어 홈(`store/index.html`)을 만들 때 참고할 스팀 게임·상점 조사  
범위: 플랫폼 개요, 상점 구조, 2026년 인기·매출 동향, 할인, 상세 페이지 구성

---

## 1. 스팀이 뭔가

스팀은 밸브(Valve)가 운영하는 **PC 게임 상점 + 런처**다. 게임을 사고, 받고, 실행하고, 친구와 플레이하는 일이 한 클라이언트 안에서 이뤄진다.

핵심 영역은 넷으로 나뉜다.

| 영역 | 하는 일 |
| --- | --- |
| 상점(Store) | 게임 탐색, 할인, 구매, 위시리스트 |
| 라이브러리(Library) | 산 게임을 실행·설치 |
| 커뮤니티(Community) | 리뷰, 창작마당, 토론, 방송 |
| 지원(Support) | 환불, 계정, 클라이언트 설치 |

공식 상점: [https://store.steampowered.com/](https://store.steampowered.com/)

유저가 홈에서 하는 일은 단순하다.

1. 추천·특가·인기 게임을 본다
2. 카드를 눌러 상세로 들어간다
3. 장바구니 / 구매 / 다운로드(라이브러리 설치)

수업 목업도 이 세 단계만 따라가면 스팀처럼 읽힌다.

---

## 2. 상점 홈은 어떻게 생겼나

실제 스팀 홈은 정보가 매우 많다. 수업에서는 **흐름만** 가져오면 된다.

### 상단

- STEAM 로고
- STORE / COMMUNITY / ABOUT / SUPPORT
- 검색
- Steam 설치, 로그인, 언어

### 본문 (자주 나오는 블록)

1. **Featured & Recommended** — 큰 배너 + 옆 리스트
2. **Special Offers** — 할인 카드 줄
3. **인기 / 신작 / 카테고리** — 가로 스크롤 또는 그리드
4. 푸터 — 약관, 환불, 밸브 로고

에픽 스토어와 비교하면:

- **정보 구조**는 스팀 (상점 → 상세 → 받기)
- **여백·히어로 배치**는 에픽 (큰 이미지 왼쪽, 게임 3개 오른쪽)

지금 만든 목업이 이 조합이다.

---

## 3. 게임 상세 페이지에 들어가는 것

밸브 공식 Steamworks 기준으로, 상점 페이지에 꼭 들어가는 자산이 정해져 있다.

### 유저가 보는 정보

- 한 줄 소개(짧은 설명, 약 300자)
- 긴 설명(About this game)
- 장르·태그·기능(싱글, 멀티, 컨트롤러 등)
- 트레일러 + 스크린샷(최소 5장, 1920×1080 권장)
- 가격 / 할인율 / 구매·위시리스트 버튼
- 시스템 요구사항
- 리뷰(매우 긍정적 등)
- 업적(있는 게임만)

### 개발자가 올리는 이미지 크기 (참고)

| 자산 | 크기 | 쓰이는 곳 |
| --- | --- | --- |
| Header Capsule | 920 × 430 | 상세 상단, 추천 위젯 |
| Small Capsule | 462 × 174 | 리스트, 검색 |
| Main Capsule | 1232 × 706 | 특집, 신작·인기 목록 |
| Vertical Capsule | 748 × 896 | 세로 카드 |
| Library Capsule | 600 × 900 | 라이브러리 세로 표지 |
| Screenshots | 1920 × 1080 이상 | 상세 미디어 |

출처: [Steamworks Graphical Assets](https://partner.steamgames.com/doc/store/assets)

수업 상세 화면은 이 중에서 **큰 이미지 + 소개 + 장르/기능 + 가격 + 다운로드**만 있어도 충분하다.

## 4. 2026년 스팀 시장 (조사 시점 기준)

시장조사업체 알리네아 애널리틱스(Alinea Analytics) 추정치를 한국 매체들이 보도한 내용이다.

- **2026 상반기 스팀 게임 판매액**: 약 **111억 달러** (한화 약 16조 원대)
- 반기 기준 역대 최대, 전년 상반기 대비 약 **14.5%** 증가
- 매출의 약 **79%는 출시 1년 넘은 구작**(백카탈로그)
- 2026년 신작 비중은 약 **21%**로, 신작보다 **할인된 구작·라이브 서비스**가 돈을 더 번다

시사점: 스팀 홈은 신작만 보여주는 곳이 아니다. **특가 줄**이 상점의 핵심이다.

무료 게임·경쟁 슈팅은 동접이 높고, 유료 신작은 매출이 높다.

## 8. 할인이 스팀의 엔진이다

밸브는 1년에 큰 할인 4번을 연다.

- 봄 / 여름 / 가을 / 겨울 세일
- 참가 게임은 상점 홈이 세일 테마로 바뀐다
- 할인율 **20% 이상**이면 위시리스트 유저에게 메일
- 일반 할인은 보통 **30일 쿨다운**이 있지만, 계절 세일은 이 쿨다운 예외
- 다만 **출시 후 30일**, **가격 인상 후 30일**은 계절 세일에도 못 들어간다
- 그 외에 일일 특가, 주중·주말 특가, 장르 페스트가 있다

2026년 예시(매체·분석 블로그 기준):

- 봄 세일: 3/19–3/26
- 여름 세일: 6/25–7/9
- 가을·겨울: 연말 추정

출처: [Steamworks 계절 할인](https://partner.steamgames.com/doc/marketing/discounts/seasonalsales?l=koreana)

목업의 **특가 줄(-50%)** 은 이 습관을 단순화한 것이다.

## 9. 장르·태그·가격 모델

스팀은 장르보다 **태그**로 게임을 나눈다. 유저가 상세에서 보는 알약은 대략 두 층이다.

- **장르**: 액션, 어드벤처, RPG, 인디, 시뮬레이션, 전략 …
- **기능**: 싱글 플레이어, 멀티플레이, 컨트롤러 지원, 클라우드 저장, 협동 …

가격 모델도 섞여 있다.

| 모델 | 예시 | 상점에서 보이는 것 |
| --- | --- | --- |
| 유료 완제품 | 사이버펑크 2077, 붉은사막 | 정가 + 할인 |
| 무료 + 아이템 | CS2, 배그, 에이펙스, 도타 2 | 무료 / 플레이 |
| 얼리 액세스 | 슬레이 더 스파이어 2, 서브노티카 2 | 앞서 해보기 배지 |
| 인디 저가 | 바이럴 시뮬·퍼즐 | $10 전후 + 큰 할인 |

그래서 카드에 `19,800원`, `-50%`, `무료`가 한 줄에 같이 있는 것이 스팀답다.

## 10. 다운로드는 어떻게 되나

실제 스팀:

1. 구매(또는 무료 추가)
2. 게임이 **라이브러리**에 들어간다
3. 클라이언트가 파일을 받아 설치한다
4. DRM은 스팀워크 연동(스팀 실행)이 기본

수업 목업:

- 상세의 **다운로드** 버튼만 있으면 된다
- 실제 설치 파일·스팀 API는 붙이지 않는다
- 버튼을 `다운로드 중…` → `다운로드 완료`로 바꾸는 정도로 충분하다

## 11. 우리 홈페이지에 바로 쓰는 포인트

`store/index.html`을 스팀 조사와 맞춰 보면:

| 스팀 | 목업 |
| --- | --- |
| Featured 큰 배너 | 왼쪽 히어로 |
| 옆 추천 리스트 | 오른쪽 게임 3개 |
| Special Offers | 특가 5장 |
| 인기 게임 | 인기 줄 5장 |
| 상세: 미디어 + 장르 + 구매 | 이미지 상단 + 태그 + 다운로드 |
| 위시리스트·장바구니·리뷰 | 수업 범위에서 생략 |

나중에 게임을 진짜 스팀 타이틀로 갈아끼울 때 추천 구성:

1. 히어로: 신작 또는 지금 할인 중인 대형작 3개
2. 특가: 구작 할인 5개 (스팀 매출의 대부분이 여기)
3. 인기: 동접 높은 무료/라이브 1~2개 + 유료 인기작
