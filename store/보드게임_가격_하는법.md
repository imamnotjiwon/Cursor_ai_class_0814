## 1. 카탄 (Catan)

- 인원 3~4인 / 60~90분 / 만 10세 / 기준가 **45,000원**
- 한 줄: 섬을 나눠 갖고, 자원을 모아 도로와 마을을 짓는다. 10점을 먼저 내면 이긴다.

**하는 법**

1. 육각 타일로 섬을 만들고, 각 칸에 숫자 토큰을 둔다. 사막에는 도둑을 둔다.
2. 시작 때 마을 2개와 도로 2개를 놓는다. 두 번째 마을 옆 지형 자원을 받는다.
3. 자기 차례: 주사위 2개를 굴린다. 나온 숫자의 칸에 마을·도시가 있으면 자원을 받는다. (남도 받는다.)
4. 합이 7이면 자원을 8장 이상 가진 사람은 절반을 버리고, 도둑을 옮긴다.
5. 그다음 거래(사람끼리, 또는 은행 4:1) 후 건설한다.
   - 도로: 벽돌+나무
   - 마을: 벽돌+나무+양+곡물 (1점)
   - 도시: 광석 3+곡물 2 (마을을 도시로, 2점)
   - 발전 카드: 광석+양+곡물
6. 최장 도로 5점, 최강 기사 2점도 있다. **합 10점이면 승리.**

## 2. 윙스팬 (Wingspan)

- 인원 1~5인 / 40~70분 / 만 10세 / 기준가 **48,000원**
- 한 줄: 새 카드를 숲·초원·습지에 놓아 엔진을 키운다. 4라운드.

**하는 법**

1. 시작 때 새 카드와 먹이, 보너스 카드를 고른다.
2. 자기 차례에 행동 하나:
   - 새 놓기 (먹이·알을 내고 서식지에 배치)
   - 숲에서 먹이 얻기
   - 초원에서 알 낳기
   - 습지에서 카드 뽑기
3. 새가 많을수록 그 줄 행동이 세진다.
4. 라운드가 지날수록 행동 횟수는 줄어든다.
5. 끝점수: 새 점수 + 알 + 저장 먹이 + 보너스 + 라운드 목표.

## 3. 코드네임 (Codenames)

- 인원 4~8인(두 팀) / 약 15분 / 만 10세 / 기준가 **29,000원**
- 한 줄: 힌트 한 단어로 우리 팀 단어를 맞힌다. 암살자를 고르면 즉시 패배.

**하는 법**

1. 5×5 단어 카드를 펼친다. 키 카드로 우리 팀·상대·시민·암살자를 나눈다.
2. 각 팀의 스파이마스터만 키를 본다.
3. 스파이마스터가 `힌트 단어 + 숫자`를 말한다. 예: `동물 2`.
4. 팀원이 그 수만큼 카드를 고른다. 우리 팀이면 계속, 시민이면 턴 종료, 상대면 상대 점수, **암살자면 즉시 패배.**
5. 자기 팀 단어를 먼저 다 맞히면 승리.

## 4. 스플렌더 (Splendor)

- 인원 2~4인 / 30분 / 만 10세 / 정가 **36,000원** · 특가 **29,000원**
- 한 줄: 보석을 모아 개발 카드를 사고, 15점을 먼저 낸다.

**하는 법**

1. 자기 차례에 하나만 한다.
   - 서로 다른 보석 3개 가져가기
   - 같은 보석 2개 (그 색이 4개 이상일 때)
   - 카드 1장 사기
   - 카드 1장 예약 + 황금(조커) 1개 (예약은 최대 3장)
2. 산 카드는 영구 할인이 된다. 다음 카드가 싸진다.
3. 특정 색 카드를 모으면 귀족이 방문해 3점.
4. **15점 이상이면 그 라운드 끝까지 하고 최고점 승리.**

## 5. 아줄 (Azul)

- 인원 2~4인 / 30~45분 / 만 8세 / 정가 **42,000원** · 특가 **35,000원**
- 한 줄: 공장에서 같은 색 타일만 가져와 줄에 채운다. 벽 한 줄이 차면 점수.

**하는 법**

1. 가운데 공장 디스플레이에서 한 색만 가져간다. 나머지는 가운데로.
2. 가져온 타일을 자기 패턴 줄에 넣는다. 한 줄은 한 색만.
3. 줄이 가득 차면 벽의 같은 자리에 타일 1장을 붙이고 점수를 받는다.
4. 남은 타일은 바닥에 버리고 감점.
5. 누군가 벽 한 가로줄을 다 채우면 마지막 라운드 후 종료. 보너스(가로·세로·한 색 완성)를 더한다.

## 6. 카르카손 (Carcassonne)

- 인원 2~5인 / 30~45분 / 만 7세 / 정가 **38,000원** · 특가 **32,000원**
- 한 줄: 타일을 이어 도시·길·수도원을 만들고, 말을 올려 점수를 받는다.

**하는 법**

1. 자기 차례에 타일 1장을 이미 나온 지형과 맞게 놓는다.
2. 원하면 그 타일에 미플(말) 1개를 올린다. 이미 주인이 있는 지형에는 못 올린다.
3. 도시나 길이 닫히면, 그 위에 말이 있는 사람이 점수를 받고 말을 돌려받는다.
4. 수도원은 주변 8칸이 다 차면 9점.
5. 타일이 떨어지면 끝나지 않은 지형도 채점한다.

## 7. 딕싯 (Dixit)

- 인원 3~6인 / 30분 / 만 8세 / 정가 **59,000원** · 특가 **47,000원**
- 한 줄: 이야기꾼이 그림에 힌트를 주고, 나머지는 비슷한 그림을 섞어 투표한다.

**하는 법**

1. 각자 그림 카드 6장.
2. 이야기꾼이 자기 카드 한 장에 짧은 힌트(말, 노래, 몸짓)를 낸다.
3. 다른 사람은 자기 패에서 그 힌트에 가까운 카드 1장을 몰래 낸다.
4. 카드를 섞어 펼친 뒤, 이야기꾼 카드를 고른다.
5. 점수: 모두 맞히거나 아무도 못 맞히면 이야기꾼은 0점. 일부만 맞히면 이야기꾼과 정답자가 득점. 자기 카드에 표가 많이 가면 추가점.
6. 말이 끝까지 가면 또는 카드를 다 쓰면 종료.

## 8. 할리갈리 (Halli Galli)

- 인원 2~6인 / 10~15분 / 만 6세 / 정가 **22,000원** · 특가 **19,000원**
- 한 줄: 카드를 뒤집어 같은 과일이 정확히 5개가 되면 종을 친다.

**하는 법**

1. 카드를 나눠 갖고, 차례로 자기 더미 맨 위를 공개한다.
2. 테이블에 보이는 같은 과일 합이 **정확히 5개**면 종을 친다.
3. 가장 빠른 사람이 공개된 카드를 가져간다.
4. 잘못 치면 카드를 나눠 줘야 한다.
5. 카드를 다 모으면 승리. (또는 한 사람이 카드를 다 잃으면 종료)

## 9. 루미큐브 (Rummikub)

- 인원 2~4인 / 30~60분 / 만 8세 / 기준가 **43,000원**
- 한 줄: 숫자 타일로 같은 숫자 세트 또는 연속 숫자를 만든다. 손 타일을 먼저 다 내면 이긴다.

**하는 법**

1. 각자 14개(또는 규칙에 따라 14~16개)를 받는다.
2. 첫 등록은 합 30점 이상의 세트를 내려놓아야 한다.
3. 이후 턴: 타일 내기, 이미 나온 줄을 재조합하기, 또는 타일 1개 가져오기.
4. 세트 예: 빨강 7-파랑 7-검정 7 / 빨강 5-6-7-8.
5. 조커는 어떤 숫자·색이든 대신한다.
6. 손 타일을 먼저 비우면 승리. 남은 사람의 타일 합이 감점.

## 10. 티켓 투 라이드 (Ticket to Ride)

- 인원 2~5인 / 30~60분 / 만 8세 / 기준가 **59,000원**
- 한 줄: 기차 카드를 모아 지도 위 노선을 점유한다. 목적지 티켓을 달성하면 큰 점수.

**하는 법**

1. 기차 말과 기차 카드 4장, 목적지 티켓을 받는다. (최소 2장 유지)
2. 자기 차례에 하나만:
   - 기차 카드 2장 가져오기 (공개 기관차는 1장만)
   - 같은 색 카드로 노선에 기차를 놓기 (즉시 점수)
   - 목적지 티켓 추가 뽑기
3. 누군가 기차 말이 2개 이하가 되면 한 바퀴 더 하고 끝.
4. 목적지 연결 성공은 가점, 실패는 감점. 최장 경로는 +10점.

## 11. 팬데믹 (Pandemic)

- 인원 2~4인 / 약 45분 / 만 8세 / 기준가 **52,000원**
- 한 줄: **협력**. 역할별로 움직이며 질병 큐브를 지우고, 치료제 4개를 만들면 전원 승리.

**하는 법**

1. 각자 역할(위생병, 과학자 등)을 받는다. 시작은 애틀랜타 연구소.
2. 자기 차례에 행동 4번: 이동, 치료(큐브 제거), 연구소 건설, 카드 공유, 치료제 발견.
3. 차례가 끝나면 플레이어 카드 2장, 감염 카드로 도시에 큐브가 늘어난다.
4. 전염(에피데믹) 카드가 나오면 감염이 급증하고, 한 도시에 큐브가 넘치면 확산.
5. 치료제 4개면 승리. 큐브가 떨어지거나, 플레이어 카드가 떨어지거나, 확산이 한계를 넘으면 전원 패배.

## 12. 웨어울프 (원나잇 얼티메이트 웨어울프)

- 인원 3~10인 / 약 10분 / 만 13세 / 기준가 **25,000원**
- 한 줄: 밤에 직업을 확인·바꾸고, 낮에 한 번만 투표한다. 한 판이 짧다.

**하는 법**

1. 인원보다 3장 많게 직업 카드를 골라 섞는다. 한 장씩 나눠 주고 3장은 가운데.
2. 자기 카드만 보고 다시 엎는다.
3. 사회자(또는 앱)가 직업 순서로 밤을 진행한다. 늑대·예언자 등이 가운데 카드나 다른 사람 카드를 본다/바꾼다.
4. 아침이 되면 토론 후 **한 번만** 투표한다.
5. 가장 표를 많이 받은 사람의 카드를 공개. 마을이 늑대를 죽이면 마을 승, 아니면 늑대 승.

(인원이 아주 많으면 여러 밤을 반복하는 클래식 마피아 규칙으로 늘릴 수 있다.)

## 13. 젠가 (Jenga)

- 인원 1인~ / 약 10분 / 만 6세 / 기준가 **18,000원**
- 한 줄: 탑에서 블록을 하나씩 뽑아 위에 쌓는다. 무너뜨린 사람이 진다.

**하는 법**

1. 블록 3개씩 방향을 바꿔 탑을 쌓는다.
2. 한 손으로만, 한 턴에 블록 1개를 뺀다. 맨 위 완성 층은 빼지 않는다.
3. 뺀 블록을 맨 위에 직각으로 놓아 새 층을 만든다.
4. 탑이 무너지면 그 사람 패배. 혼자 하면 무너지기 전 층 수가 기록이다.

## 홈페이지에 반영한 방식

- `data-desc`: 한 줄 소개 + 핵심 규칙
- `data-more`: 하는 법 요약 + 구성·배송
- `data-features`: 인원, 시간, 연령
- `data-price`: 위 표의 홈 표시 가격
- 특가 5종만 정가 취소선 + 할인가

출처: 오픈마켓 시세(퍼니즈/11번가 2026), 보드라이프, 나무위키·보드게임 가이드(카탄, 윙스팬, 스플렌더, 딕싯, 티켓 투 라이드, 팬데믹, 원나잇 웨어울프).
